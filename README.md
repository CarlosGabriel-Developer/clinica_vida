# 🏥 Sistema Clínica Vida+

Sistema simples desenvolvido em **Python** para cadastro e gerenciamento de pacientes de uma clínica.

O projeto foi desenvolvido como um **Projeto Integrado**, com o objetivo de praticar conceitos fundamentais da programação em Python, como listas, dicionários, funções, estruturas de repetição e tratamento de erros.

## 📋 Funcionalidades

O sistema permite:

* 👤 Cadastrar pacientes
* 📊 Visualizar estatísticas dos pacientes
* 🔎 Buscar um paciente pelo nome
* 📋 Listar todos os pacientes cadastrados
* 🚪 Encerrar o programa

### 📊 Estatísticas

O sistema calcula automaticamente:

* Número total de pacientes cadastrados
* Idade média dos pacientes
* Paciente mais novo
* Paciente mais velho

## 🛠️ Tecnologias utilizadas

* **Python 3**
* Listas
* Dicionários
* Funções
* Estruturas condicionais
* Estruturas de repetição
* Tratamento de erros com `try/except`
